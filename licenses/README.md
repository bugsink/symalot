# Third-party notices

Generated by scripts/vendor_licenses.py from cargo metadata --locked.
Each directory identifies an exact dependency version, including build
and target-specific dependencies. SOURCE.json records the published crate,
authors, declared license, copied paths, and any fallback source.

Symbolic crates omitting their license file use the upstream release's
LICENSE. Other crates omitting license text select Apache-2.0 only when
explicitly offered as a standalone alternative in their Cargo metadata.
Their notices and authorship are preserved alongside the standard text.

These notices ship in wheels and source distributions. Release builds
regenerate them to follow dependency updates; do not edit generated files.
